# Merchant Settings থেকে Default Template Reset সরানো

## পরিবর্তন
- Store Information page থেকে পুরো “Danger Zone” অংশ সরানো হবে।
- “Reset to Default Template” button ও confirmation popup আর থাকবে না।
- অপ্রয়োজনীয় reset-related code/import পরিষ্কার করা হবে।
- Store Information-এর সব field এবং “Save Store Information” button অপরিবর্তিত থাকবে।

## যাচাই
- Mobile view-তে Business Information-এর পর সরাসরি Save অংশ দেখা যাবে।
- Store settings save স্বাভাবিকভাবে কাজ করবে এবং app build error-free থাকবে।
